# Publication scope

**RETAILERWAY LLC**

This is a separate documentation and visual-evidence publication prepared under
the owner's instruction to **never share the project's source code**. The
original project directory and any project history were not imported. The
publication history contains individually selected evidence files only.

Published contents:

- English experiment report, methods, limitations, sources, and media catalog.
- Scientific PNG figures, GIF previews, and MP4 simulation recordings.
- Selected numerical results and media-integrity metadata, without source code.
- A checksum list and Git ignore rules allowing only the selected publication files.

Source code, scripts, notebooks, tests, execution commands, dependency files,
logs, configurations, model weights, checkpoints, raw regional traces, and raw
brain/EEG data remain outside this publication. Local paths and credentials
have been excluded from the public documentation.

English labels and RETAILERWAY LLC stamps were applied to the evidence using
the original recorded numerical data and simulator captures. Results, event
timing, and playback rates remain the same; presentation layouts and file
hashes change. The full learning capture now includes a branding footer.
Older commits preserve the initial publication as version history.

The repository alone cannot reproduce training or analysis because the code
and weights are private. Published media, reports, and integrity digests can
be inspected. Regional E/I values remain dimensionless; the human reference
retains µV. Human-like electrical or emotional processing is not claimed to
have been validated.

Branding does not grant an open-source license or rights to the private project
code, and does not claim ownership of third-party datasets. Their rights and
attribution remain with their respective providers. The original human EEG
provider's CC0 license is documented in [Sources](docs/sources.md).
